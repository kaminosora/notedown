# Notedown 1.3.1 — 阅读态表格拖动

根据手机使用反馈，将表格拖动从富文本编辑器移到日常阅读页面，避免长按输入区域弹出键盘、遮住表格。

- 阅读时长按表格左侧点状手柄移动整行，上侧点状手柄移动整列；手柄与列表使用一致的 `⠿` 点状样式。
- 长按单元格，与目标格交换内容，两格内容都保留。松手自动保存，写入失败恢复原笔记。
- 手柄位于表格外侧，拖到页面边缘自动滚动；宽表支持横向滚动。返回、Escape、取消触摸或拖出表格可取消操作。
- 编辑模式移除表格拖动手柄与长按拖动，保留文字输入、选择、增删行列及整表操作。
- 表格与列表的长按事件互不抢占；修复列表拖完后立即打开编辑器时，可能读到尚未落盘的旧顺序的问题。
- 保留 LaTeX 公式、60%–150% 显示比例及现有编辑功能。含合并单元格的表格仍支持内容交换，暂不支持整行整列排序。

下载 `notedown-1.3.1-debug.apk` 覆盖安装即可，Android 8.0 及以上。沿用旧签名，无需卸载；附件提供 SHA-256 校验文件。

阅读态拖动与列表一样自动保存，不进入富文本编辑器的撤销历史。验证结果见仓库 `docs/verification-v1.3.1.md`。

验证：网页／存储 134 项／组、MuMu Android 15 原生 17 组通过，包含阅读长按期间键盘不显示、页面连续滚动、默认及手机密度缩放操作。修复了旧 WebView 触摸捕获转移导致的中断问题；尚未在 Redmi K80 Pro 实体机验收。
