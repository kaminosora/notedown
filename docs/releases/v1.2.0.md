# Notedown 1.2.0 — 富文本与手机编辑体验改进

本次更新重做了富文本编辑操作与撤销记录，改善手机键盘遮挡、复杂内容操作和长文选择体验。笔记继续以安全 HTML 保存在本地；编辑器依赖随 APK 离线打包。

## 编辑功能

- 统一标题、粗体、斜体、删除线、行内代码、引用、列表、代码块、链接与清除格式操作，支持撤销和重做。
- 修复跨段落任务列表转换、勾选状态撤销、任务换行延续及空任务退出。
- 新增内容块和列表项的上移、下移、前后插段、删除；图片、代码、分割线和表格也可以操作。
- 表格支持新增／删除行列、删除整表；在最后一个单元格按 Tab 可增加一行。
- 表格标题（`caption`）在富文本中只读，需修改时切换 HTML 模式，避免误改后内容丢失。
- 修复倒序有序列表在分割或转换时的编号。
- 修复链接编辑、结构化粘贴、拖入落点和内部文字拖动，避免重复插入或破坏段落结构。

## 手机编辑

- 工具栏改为两条可横向滑动的操作栏，增大触控区域；滑动不触发格式命令。
- 修复正文滚动时从吸顶工具栏上方露出的问题，已通过 412px 与 640px 宽度专项回归。
- 键盘显隐时调整编辑可视区域，输入时自动露出正文或源码光标。
- 新增“光标”和“选区”手柄，拖到正文上下边缘可持续滚动。只有正在拖动的一端随手柄改变，另一端滚出屏幕后仍保持原位置。
- 限制正文选区边界，避免选中工具栏、页面提示等其他界面元素；切换模式或关闭编辑器会清理拖选状态。
- Android 原生布局统一处理系统栏、挖孔与键盘占位，避免重复留白。

## 内容保真与保存

- 保留代码语言、空行和缩进，修复多段任务与嵌套列表的 Markdown 往返。
- 合并单元格、复杂表格及无法用 Markdown 精确表示的内容保留安全 HTML。
- 保存成功后才更新已保存状态；保存失败保留编辑草稿或恢复已保存阅读内容，并允许重试。
- 修复带 BOM 的 UTF-16 文本在 Android 导入时被误判为二进制文件的问题。

## 应用图标

- 更换为深蓝紫底的折纸 N 图标，使用暖金与珊瑚色折面。
