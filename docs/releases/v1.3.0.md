# Notedown 1.3.0 — 表格拖动、LaTeX 公式与显示比例

本版基于已合并的社区贡献继续开发，保留未保存修改退出确认、损坏笔记恢复及关闭系统云备份的改动。

## 应用内显示比例

- 新增 60%–150% 的显示比例，以 5% 为步长，缩小后可在手机上显示更多内容。
- 入口位于书架右上角 **Aa** 按钮、笔记页 `⋯` 菜单，以及富文本第二条工具栏的“比例”按钮。
- 支持滑杆、加减按钮和 65%／80%／100%／125% 预设；调整可预览，点击“保存”后记住比例。
- “取消”或系统返回会恢复原有比例；“恢复默认”预览 100%，保存后生效。保存失败会回到原比例并允许重试。
- 系统字体较大时建议先试 80%，想显示更多内容可再试 65%。只影响 Notedown，不修改系统设置或笔记内容。
- 桌面浏览器请使用浏览器菜单中的缩放，应用内比例使用的移动视口缩放在桌面浏览器中不生效。

## 表格拖动

- 富文本中长按表格左侧的行柄或上侧的列柄，选中整行或整列并拖动排序；其余行列保持相对顺序。
- 长按单元格并拖到另一格，松手后交换两格内容。采用交换模式，保留目标原有内容，不会直接覆盖。
- 拖动时显示来源、落点和操作提示；靠近上下边缘自动滚动，移到表格外或取消触摸不改变内容。
- 一次拖动对应一次撤销；手柄不会进入笔记正文。
- 合并单元格支持内容交换；整行整列移动暂不适用于含合并格的表格，会明确提示，避免破坏结构。

## LaTeX 公式

- 支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`，可用于 Markdown / HTML 源码；代码块和行内代码不解析公式。
- 富文本右上角新增 ƒx 开关，显示或隐藏第三行公式工具，并记住偏好。
- 提供行内、独立公式与分式、根式、上下标、求和、积分、矩阵模板，以及源码编辑和即时预览。
- 单击选中公式后可编辑；双击或按 Enter 也可打开。插入、修改和删除都支持撤销。
- 公式保存原始 LaTeX，切换编辑模式、保存重开仍可编辑。错误公式保留源码；排版引擎与字体离线打包。

## 合并兼容修复

- 修复“放弃未保存的修改”确认框被编辑器遮住而无法点击的问题；确认时暂停底层编辑器交互。
- 保留社区贡献的草稿退出保护、损坏数据恢复、启动快照与关闭 Android 自动备份行为。

## 安装

下载 `notedown-1.3.0-debug.apk` 覆盖安装，Android 8.0 及以上。沿用旧版签名，无需卸载。附件 `SHA256SUMS-1.3.0.txt` 提供安装包校验值。

完整验证结果见仓库 `docs/verification-v1.3.0.md`。
